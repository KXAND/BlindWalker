# ADR 0017: WASD 四向连续移动

**日期**: 2026-08-12  
**状态**: Accepted  
**修订**: ADR-0003

---

## 上下文

ADR-0003 将离散步态替换为按住 W 的连续前进。该方案降低了操作复杂度，但玩家无法在不转动身体朝向的情况下横移、后退或微调位置；地形探测和撞墙反馈也只面向身体前方。

当前关卡需要玩家在保持盲杖和视角方向时调整站位，因此输入模型需要扩展为四向连续移动，同时保留 ADR-0003 的连续移动、谨慎模式和高抬腿模式。

## 决策

采用相对玩家身体朝向的 WASD 四向移动：

| 输入 | 局部方向 |
|------|----------|
| W | 前方 |
| S | 后方 |
| A | 左侧 |
| D | 右侧 |

- `InputManager` 每帧轮询四个按键，构造二维移动向量并传递给 `GaitController`。
- `GaitController` 将向量限制为单位长度，再以玩家 `global_transform.basis` 转为世界方向；斜向移动不获得额外速度。
- 地形高差探测、台阶处理和撞墙后的踉跄推回均使用实际移动方向，而不是固定的身体前方。
- SHIFT 与 SPACE 仍分别表示谨慎和高抬腿，对任意移动方向生效。

## 影响

- 玩家可在不改变视角或盲杖方向的情况下调整位置、后退和横移。
- 侧向或后退靠近台阶、落差和墙面时，反馈会与真实运动方向一致。
- WASD 使移动输入比 ADR-0003 的单键前进更复杂，但不恢复离散步态的交替按键与状态机复杂度。
- `GameConfig` 增加 `KEY_BACKWARD`、`KEY_LEFT` 和 `KEY_RIGHT` 常量；`GaitController` 的输入接口改为接收移动向量。

## 不在范围内

- 不增加自动转向、相机跟随转向或冲刺机制。
- 不改变盲杖扫动、谨慎模式、高抬腿模式及其数值规则。
- 不通过 InputMap 新增动作名；现有项目直接使用键位常量的模式保持不变。
