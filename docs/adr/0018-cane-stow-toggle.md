# ADR 0018: 盲杖收放切换

**日期**: 2026-08-12
**状态**: Accepted

---

## 背景

盲杖原本始终展开并参与扫动、环境接触、杖触记忆和 NPC 避让。玩家需要能够暂时收起盲杖，在不改变视角和移动方式的前提下直接观察或调整位置。

## 决策

使用 T 键在盲杖展开与收起之间切换。

- 收起开始时立即停用盲杖的扫动、环境查询、杖触记忆、碰撞 Area 和 NPC 避让；收起完成后隐藏杖身。
- 展杖动画完成后才恢复盲杖功能，收放动画期间忽略重复切换。
- 收放以位于相机下方、视野外的手端为枢轴。收起时杖尖旋转至竖直向下，使杖身移出画面；展杖反向回到收起前的扫动姿态。
- 收起或过渡期间，盲杖不消耗鼠标位移，鼠标全部控制玩家视角。
- 收放动画时长固定为 `0.25s`，使用平滑的 ease-in-out 曲线。

## 考虑的替代方案

| 方案 | 否决理由 |
|------|---------|
| 仅隐藏杖身 | 盲杖仍能碰撞和触发反馈，状态与视觉不一致。 |
| 收起动画结束后才禁用功能 | 动画期间仍可能产生杖触记忆或触发 NPC，结果不可预测。 |
| 将杖尖向上收起 | 杖身会穿过相机视野，无法表达收在手边。 |
| 收起后保留盲杖鼠标输入 | 玩家无法自然转动视角，且没有可见的扫杖反馈。 |

## 验收要求

- T 在 gameplay 状态下触发展开与收起；设置菜单、叙事和其他非 gameplay 状态不触发。
- 收起开始后，盲杖不再产生接触音效、杖触记忆或 NPC 避让。
- 收起动画以手端为固定枢轴，结束时杖身不可见。
- 展杖完成前不恢复盲杖功能；完成后恢复原扫动姿态与所有感知行为。
- 收起和过渡期间，鼠标直接控制视角。
- 临时验证脚本完成后移除。
