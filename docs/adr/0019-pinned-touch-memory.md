# ADR 0019: 持久触觉记忆点

**日期**: 2026-08-12
**状态**: Accepted

---

## 背景

手触和杖触会生成短期显影球与长期残影球，但两者都会自然衰减。玩家需要能主动保留关键位置，以便在探索中维持少量可靠的空间锚点。

## 决策

- 左键用于手触，右键用于切换屏幕中心射线命中的触觉记忆点保留状态。
- 本决策替代 ADR-0007 中关于鼠标按键映射的部分，其余手触与杖触共享显影的设计保持不变。
- 保留的单位是完整记忆点：显影球与残影球同时停止衰减。右键未命中时不产生效果；再次命中已保留点会取消保留。
- 玩家最多保留 8 个记忆点；新增第 9 个时取消最早保留者。
- 保留记忆优先进入后处理着色器的球数量预算，避免被临时显影挤出画面。
- 保留状态仅存在于当前游戏场景生命周期，重开、回到主页或刷新后清空。

## 考虑的替代方案

| 方案 | 否决理由 |
|------|---------|
| 右键未命中时回退保留最新记忆 | 容易在玩家没有明确指向目标时误保留。 |
| 只保留显影球或残影球 | 同一触觉记忆点的即时反馈与位置标记会分离，语义不完整。 |
| 达到上限后拒绝新保留 | 玩家需要额外管理操作才能更新关键锚点。 |
| 将保留状态持久化到重开或主页 | 世界和玩家位置已经重置，旧锚点会失去空间语义。 |

## 后续
